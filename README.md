AWS Glosario

Glosario interactivo de conceptos y servicios de AWS, organizado por módulos y categorías.

Características
Módulo 1 y Módulo 2
Buscador de conceptos
Filtros por categoría
Navegación entre módulos con JavaScript
Diseño adaptable a PC, tablet y móvil

Tecnologías
HTML5
CSS3
JavaScript

Proyecto realizado como material de apoyo para el curso de AWS Academy.
